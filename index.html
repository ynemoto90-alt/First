Altimeter / Kollsman Simulator

ISA標準大気式を使った教育用シミュレータです。実高度、海面更正気圧(QNH)、Kollsman設定を独立して変更し、 静圧と指示高度の関係を確認できます。

Kollsman Window
「Set indication 0 ft」は、現在地点の静圧から、その高度計が0 ftを示すKollsman値を逆算して設定します。 地上で実行すればQFEの感覚を確認できます。
Preset Experiment
Model
Troposphere ISA lapse-rate equation is used. Static pressure is calculated from true MSL altitude and the selected QNH. Indicated altitude is then derived from that static pressure using the Kollsman setting as the reference pressure.
